# Verdugo Labs website

Responsive single-page website for Verdugo Labs. The complete page, including styles, is in `index.html`.

## Edit the website

Open `index.html` on GitHub, click the pencil icon, change the text, and commit to `main`. Once Render is connected, it automatically publishes commits to that branch.

Search for `your-email@example.com` to replace the contact email. Update both the mail link and the displayed address, then remove the visible placeholder notice.

## Render settings

- Service type: Static Site
- Branch: `main`
- Build command: `echo "Static HTML; no build required"`
- Publish directory: `.`
- Auto-deploy: On Commit

Add `verdugolabs.ai` in the service's Custom Domains settings and follow the DNS instructions supplied by Render. Domain registration and DNS verification are separate from creating the hosted site.

## Local preview

Open `index.html` in your browser. No server or dependencies are required.
